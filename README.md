# Sujay Portfolio

Personal developer portfolio built with Vite + React + TypeScript + Tailwind + shadcn/ui.

## Development

This repo includes a Bun lockfile (`bun.lockb`). Use Bun or npm.

### Bun

```sh
bun install
bun run dev
```

### npm

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
